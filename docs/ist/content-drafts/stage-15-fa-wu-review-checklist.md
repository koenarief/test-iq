## Checklist umum per record

- [ ] Logical ID, kind, dan display order tepat serta unik.
- [ ] Prompt dan lima opsi dapat dibaca pada desktop serta mobile.
- [ ] Tepat satu opsi correct dengan skor 1; empat opsi lain skor 0.
- [ ] Alt text netral dan nama file tidak membocorkan key.
- [ ] Aset monokrom, tajam, dan tidak memakai warna sebagai petunjuk.
- [ ] Difficulty diperlakukan sebagai label editorial.
- [ ] Konten terlihat orisinal dan tidak menyerupai instrumen lain.
- [ ] Metadata lengkap; `review_status=in_review`; `active=false`.

## Review FA

- [ ] Seluruh potongan prompt dipakai tepat satu kali pada opsi benar.
- [ ] Tidak ada overlap, peregangan, penambahan, atau penghilangan bagian.
- [ ] Rotasi legal; refleksi tidak digunakan pada opsi benar.
- [ ] Empat distraktor mustahil secara geometris dan mempunyai rationale berbeda.
- [ ] Tidak ada opsi kedua yang lolos penyusunan.
- [ ] Audit area, komposisi, topologi, rotasi, dan refleksi dapat ditelusuri.
- [ ] Lekukan dan fragmen tetap jelas pada ukuran kecil.
